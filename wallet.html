bitcoin-kernel / browser-node — wallet (sign a testnet4 spend)

Build and sign a P2WPKH spending transaction in your browser. The signing key never leaves this tab. Load a wallet mnemonic, point at a UTXO funding your 0/0 address (find it with the watch-only scan), and this page produces a signed, broadcast-ready transaction — verified against the node's own BIP143 verifier before you ever see it. how it works

⚠ Testnet4 only — throwaway. Your mnemonic is your wallet; it stays in this tab and vanishes on reload. This page signs and broadcasts — the signed transaction is announced to a real testnet4 peer over the bridge. You can also copy the raw hex and push it elsewhere.

Signs the input at whichever m/84'/1'/0'/{0,1}/i address holds the UTXO — it searches your first 20 receiving and change addresses for the funding address and uses that key (P2WPKH, BIP143). Change returns to the funding address. The signature is produced by the bundled WASM secp and the finished transaction is checked by the node's own ScriptInterpreter.verifyInput before display — the same code path that validates blocks. Broadcast fans the tx out to several testnet4 peers over the bridge (inv → getdata → tx, the bridge dialing a random peer per connection) and stops once one admits it — so a single peer missing an unconfirmed parent can't sink it. Proven end-to-end in test-sign.mjs / test-wallet.mjs / test-broadcast.mjs / test-broadcast-multi.mjs.
