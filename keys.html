bitcoin-kernel / browser-node — keys (generate a testnet4 wallet)

Generate a fresh testnet4 wallet in your browser. This is the one page in this project that touches private keys — everything else is watch-only/verification. The seed is created locally (crypto.getRandomValues) and never leaves this tab. Take the account tpub to the watch-only wallet, and fund a receiving address from a testnet4 faucet. how it works

⚠ Testnet4 only — throwaway. Do not use for real funds. The seed below is your wallet; anyone who sees it controls it. This is a demo: keys live only in this tab and vanish on reload (write the seed down if you want to keep the wallet).

Path: BIP84 m/84'/1'/0' (testnet account), receiving chain 0/i, P2WPKH. Private/hardened BIP32 keygen uses the bundled WASM secp (pointFromScalar / privateAdd), verified against BIP32 spec vector 1 (test-keygen.mjs). Next: a BIP39 mnemonic for the backup, and signing/spending.
