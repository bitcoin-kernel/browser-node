bitcoin-kernel / browser-node — mesh (block propagation · PoC)

Open this page in two tabs (or send the link to a friend). The two tabs become Bitcoin peers to each other over WebRTC — no server in the data path — meeting in a room on a signaling server. Hit Seed 5000 in one tab: it pulls 5000 real blocks from the network (via the bridge) and propagates them to the other tab over the channel, which validates every one (proof-of-work + merkle root). That's block propagation at volume, in a browser mesh. the node · how it works
