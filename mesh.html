bitcoin-kernel / browser-node — mesh (block propagation · PoC)

Open this page in two or more tabs (or send the link to a friend). The tabs become Bitcoin peers to each other over WebRTC — no server in the data path — every tab connects to every other (a full mesh) in a room on a signaling server. Hit Seed 5000 in one tab: it pulls 5000 real blocks from the network (via the bridge) and propagates them to the other peers, which validate every one (proof-of-work + merkle root). That's block propagation at volume, in a browser mesh. the node · how it works

PoC scope: Seed 5000 pulls real blocks from the network (via the bridge) and relays them to the peer, each validated for structure + proof-of-work (no UTXO set, so not full-consensus). Every tab connects to every other (full mesh), and a received block is gossiped onward to other peers (deduped by a seen-set), so it propagates across the mesh, multi-hop. Next: stream the full chain. Default room c0ffeebabe123456; override with ?room=<hex>, the signaling server with ?signal=wss://your.pod/.webrtc, and the block count with ?blocks=N (default 5000).
