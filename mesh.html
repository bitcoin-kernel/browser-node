bitcoin-kernel / browser-node — mesh (block propagation · PoC)

Open this page in two tabs (or send the link to a friend). The two tabs become Bitcoin peers to each other over WebRTC — no server in the data path — meeting in a room on a signaling server. Then one tab relays a block to the other: it announces it (inv), the other requests it (getdata), receives the block, and validates it (proof-of-work + merkle root). That's block propagation, in a browser mesh. the node · how it works
